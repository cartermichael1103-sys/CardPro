Privacy Policy

Sports Card Break Value Index / New Listing tool

← Back to Index

This is a personal, single-user tool for tracking sports card values and drafting eBay listings. It is not a commercial product and does not have other users besides its owner.

What data this tool handles

  • Card photos you upload to the New Listing tool are sent to Anthropic's Claude API for identification, and (if you choose to save a draft to eBay) copied to a private Cloudflare R2 bucket so eBay's listing API can reference them.
  • eBay account access: if you connect your eBay account, this tool stores an OAuth refresh token that lets it create draft offers on your behalf, using eBay's Sell API. Drafts are never published without you explicitly clicking Publish and confirming a warning that the action is immediate and irreversible. It does not read or store any other eBay account data beyond what's needed for this (e.g. your existing shipping/return policy IDs, so it can attach them to a draft).
  • Shipping address: eBay requires a registered shipping-from location to publish a listing. If you use the Shipping Location setup on My eBay Drafts, the address you enter is sent directly to eBay to register that location — it is not stored anywhere else by this tool.
  • No data is sold, shared, or used for any purpose other than operating this tool for its owner.

Third parties involved

  • Anthropic (Claude API) — processes uploaded card photos for identification
  • eBay — receives listing data (title, description, price, photos, category) when a draft is saved
  • Cloudflare — hosts the backend (Workers), the refresh token (KV), and card photos (R2)
