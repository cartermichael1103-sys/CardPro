My eBay Drafts

Unpublished offers saved to your eBay account via the New Listing tool

← New Listing

These exist as real objects in your eBay account but are not published — eBay's own website generally won't show you these anywhere (a known gap in how their Inventory API and Seller Hub relate, not something we can fix from here). This page reads them directly from eBay's API instead, so you can review before deciding what to do with each one.

This page isn't connected to a listing-draft backend yet. Set WORKER_URL at the top of my-drafts.js to your deployed Cloudflare Worker URL.
