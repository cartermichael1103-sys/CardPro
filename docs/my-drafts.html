My eBay Drafts

Unpublished offers saved to your eBay account via the New Listing tool

← New Listing

These exist as real objects in your eBay account but start out not published — eBay's own website generally won't show unpublished drafts anywhere (a known gap in how their Inventory API and Seller Hub relate, not something we can fix from here). This page reads them directly from eBay's API instead, so you can review before deciding what to do with each one. Use Publish when you're ready to make a listing live — that step is irreversible from here and asks you to confirm first.

This page isn't connected to a listing-draft backend yet. Set WORKER_URL at the top of my-drafts.js to your deployed Cloudflare Worker URL.

Shipping Location

eBay requires a registered shipping-from location to publish a listing — this is a separate, API-only setting that doesn't appear anywhere in eBay's normal seller dashboard, so this tool sets it up directly. Your address is sent straight to eBay to register the location; it is not stored anywhere else by this tool.
